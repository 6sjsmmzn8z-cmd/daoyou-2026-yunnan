云南省文化和旅游厅办公室关于组织实施2026年全国导游资格考试（云南考区）的通知

        2026-10-13
        72 阅读

来源：云南省文化和旅游厅办公室《关于组织实施2026年全国导游资格考试（云南考区）的通知》（成文日期2026年8月5日），2026年8月6日发布于云南省文化和旅游厅官方网站通知公告栏目，转发依据为《文化和旅游部办公厅关于组织实施2026年全国导游资格考试的通知》（办市场函〔2026〕396号）。本文文字照录官方发布，仅按网页版式重新分段，未作增删；如与官方文本有出入，以发文机关当年公告为准。
昆明市、昭通市、红河州、西双版纳州、大理州、丽江市文化和旅游局：
根据《文化和旅游部办公厅关于组织实施2026年全国导游资格考试的通知》（办市场函〔2026〕396号）要求，定于2026年11月至12月举行2026年全国导游资格考试。现将有关事项通知如下：
一、报名条件
（一）中华人民共和国公民；
（二）具有高级中学、中等专业学校或者以上学历；
（三）身体健康；
（四）具有适应导游需要的基本知识和语言表达能力。
二、报名程序
全国导游资格考试报名采取网上报名的形式进行，报名程序包括提交报名信息、报名信息审核、交费和下载准考证4个环节。
（一）提交报名信息
2026年8月7日9:00至9月14日17:00，考生可通过全国导游资格考试网上报名系统提交报名信息，网址为https://mr.mct.gov.cn（全国旅游监管服务平台—全国导游资格考试报名入口），手机移动端可通过“文旅之声”微信公众号提交。考生须上传符合要求的本人近期1寸白底免冠证件照片、身份证扫描件（包括正、反两面，身份证有效期须覆盖考试日期）、学历证书扫描件并填报相关信息，上传材料的具体要求参见全国导游资格考试网上报名系统。考生不得在多地重复报名。
（二）报名信息审核
2026年8月7日9:00至9月18日17:00，各审核点对考生提交的报名信息进行审核。报名信息审核通过后，考生报名信息不再予以变更。
（三）交费
考生通过报名信息审核后可以交费，截止时间为2026年9月24日17:00。交费成功后，考生因个人原因不能参加考试的，不予退费。按照云价收费〔2010〕83号文件规定收费，笔试（机考）科目一、科目二、科目三、科目四共计4科，50元/人.科；由于原国家旅游局已经取消5元/人.科国家收费，为减轻考生负担，云南省2026年按照45元/人.科收取笔试（机考）考试费用。现场考试（面试）按照100元/人.次收取。
（四）下载准考证
2026年11月16日9:00起，考生可通过网址https://mr.mct.gov.cn或“文旅之声”微信公众号登录全国导游资格考试网上报名系统下载准考证并自行打印。报名信息审核未通过或未交费的考生，无法下载准考证。
三、审核点和考点设置
（一）审核点设置
2026年全省共设8个网上审核点（其中昆明市设3个），网上审核工作由各审核点完成，全省外语类考生报考点统一设在云南省文化和旅游培训中心。
（二）考点设置（笔试与现场考试考点相同）
2026年全省设置6个考点：昆明市、昭通市、红河州、西双版纳州、大理州、丽江市，请考生就近选择。
四、考试科目和考试大纲
考生报考全国导游资格考试，须同时参加笔试和现场考试（面试）。已经取得“导游资格证书”，需增加其他语种的考生（以下称“加试考生”）仅须参加现场考试（面试）。
（一）笔试
1.笔试采取机考方式进行，科目为《政策与法律法规》《导游业务》《全国导游基础知识》和《地方导游基础知识》。其中，《政策与法律法规》《导游业务》合并为1张试卷进行测试，《全国导游基础知识》《地方导游基础知识》合并为1张试卷进行测试，每张试卷满分100分，考试时间均为90分钟。
2.外语考试语种。2026年云南考区外语考试语种为：英语、法语、朝鲜语、日语、泰语、缅甸语、越南语和老挝语8个。
（二）现场考试（面试）
1.现场考试（面试）科目为《导游服务能力》，满分100分。
考试采用人机对话方式进行（现场考试流程随后公告），考试题目在考试当天由考试系统随机抽取确定。
2.中文景区景点讲解采取“抽三选一”的方式进行，即随机抽取其中三个景区景点，考生任选一个进行讲解；外语景区景点讲解采取随机抽取其中一个景区景点进行讲解的方式进行。
3.加试外语语种的考生，只参加该语种《导游服务能力》考试。
4.现场考试（面试）按《全国导游人员资格考试现场考试工作标准（试行）》有关规定执行。
（三）考试大纲
2026年全国导游资格考试笔试大纲可通过文化和旅游部政府门户网站（www.mct.gov.cn）下载，现场考试（面试）大纲可通过云南省文化和旅游厅官方网站(https://dct.yn.gov.cn)下载。
五、考试时间
科目考试时间
《政策与法律法规》《导游业务》2026年11月21日9:00—10:30
《全国导游基础知识》《地方导游基础知识》2026年11月21日10:30—12:00
《导游服务能力》于2026年12月21日前组织完成（考试时间和地点以准考证为准）
六、考试结果公布
考生的考试结果以笔试成绩、现场考试（面试）成绩均满足划线要求为合格。加试考生的考试结果以现场考试（面试）成绩满足划线要求为合格。考生的考试成绩当年有效。
2027年3月1日9:00起，考生可通过网址https://mr.mct.gov.cn或“文旅之声”微信公众号登录全国导游资格考试网上报名系统查询考试结果。
七、考试结果复核
考生需要对本人考试结果进行复核的，可自考试结果公布之日起5个工作日内（即2027年3月5日17:00前），向复核点提出复核申请，复核结果为最终结果，不予再次复核。考试结果复核工作按《全国导游人员资格考试管理办法（试行）》有关规定办理。
八、证书核发
对考试合格的考生，文化和旅游部委托省文化和旅游厅核发“导游资格证书”。考生领取证书须提供与报名信息一致的材料原件，供发证人员核验。
九、其他报考事项
（一）香港、澳门和台湾居民报考要求
香港、澳门永久性居民中的中国公民报考全国导游资格考试，按《关于香港、澳门永久性居民中的中国公民报考全国导游人员资格考试有关事项的通知》（旅办发〔2008〕174号）执行，报名过程中也可提供中华人民共和国港澳居民居住证供资格审核。
台湾居民报名参加全国导游资格考试，须提交中华人民共和国台湾居民居住证或台湾居民来往大陆通行证供资格审核。台湾居民参加全国导游资格考试的其他要求与大陆考生相同。
（二）中等职业学校旅游类专业报考要求
2027届中等职业学校旅游类专业毕业生可以报名参加考试，考试合格且取得毕业证书，方可领取“导游资格证书”。
十、有关工作要求
各有关州市文化和旅游局要高度重视考试工作，加强管理、落实责任、严肃纪律，确保2026年全国导游资格考试顺利举行。
（一）加强考试管理。各有关州市文化和旅游局要加强对考试工作的全过程管理，严格报名信息审核工作，规范行政审批程序，切实维护好考试的公平性、公正性和权威性。
（二）落实考务责任。各有关州市文化和旅游局要进一步落实考务责任，强化履责意识，提高履职能力。对在辖区内考试组织工作中玩忽职守、失职渎职、推诿拖延、擅离职守、隐瞒实情、漏报谎报等违反相关规定的单位和个人，严肃问责追责并予以通报。构成犯罪的，移交司法机关依法追究刑事责任。
（三）严肃考风考纪。各有关州市文化和旅游局要采取有效措施防范考试违规违纪行为的发生，做好辖区内考试工作的巡视和监管工作。对于考试中出现的违规违纪行为，一经查实立即依规依纪予以严肃处理。
云南省文化和旅游厅办公室
2026年8月5日
附件：2026年全国导游资格考试（云南考区）审核点联系方式
云南考区考生怎么用这份通知（本站整理，非官方内容）
云南考区的属地特征是考点和审核点分开：笔试与现场考试共用6个考点——昆明市、昭通市、红河州、西双版纳州、大理州、丽江市，通知要求就近选择；网上审核点全省8个，其中昆明市设3个，审核工作由各审核点完成而不是省厅统一做，外语类考生的报考点则统一设在云南省文化和旅游培训中心。提交报名信息为2026年8月7日9:00至9月14日17:00，审核到9月18日17:00，审核通过后报名信息不再予以变更。
费用口径在云南做过下调：按云价收费〔2010〕83号文件原为50元/人·科，因原国家旅游局取消5元/人·科的国家收费，2026年云南省按45元/人·科收笔试（机考）费用，四个科目都要考；现场考试（面试）按100元/人·次收取。交费截止2026年9月24日17:00，交费成功后因个人原因不能参加考试的不予退费。
现场考试是云南差别最大的一块：科目《导游服务能力》满分100分，采用人机对话方式，题目在考试当天由考试系统随机抽取，中文景区景点讲解按「抽三选一」进行，外语类随机抽一个讲解；加试外语语种的考生只参加该语种考试，2026年云南考区开放英语、法语、朝鲜语、日语、泰语、缅甸语、越南语、老挝语8个语种。《导游服务能力》须在2026年12月21日前组织完成，考试时间和地点以准考证为准，现场考试流程随后公告。通知文末另有附件《2026年全国导游资格考试（云南考区）审核点联系方式》，各审核点电话以官方页面发布的附件为准；讲解备考可参考景点讲解怎么准备，笔试范围见2026年笔试大纲发布通知。
