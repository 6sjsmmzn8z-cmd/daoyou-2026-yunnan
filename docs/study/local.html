科目四｜地方导游基础知识：全国地区、云南景点分类记忆表

先读 学习入口 和学习记录，再决定问哪些题。 本表供查阅和背诵，不表示表内知识都需要重复提问。今天没有系统诊断本科，各项具体地区对应默认“尚未验证”，不能写成“不会”或“已掌握”。

按2026笔试大纲整理，覆盖全国各省级地区及港澳台；分类与例子用于建立记忆框架，不是官方命题频率或押题清单。先记“地区—资源—文化”的对应，再补教材中的地理、历史、经济、交通细节。

1. 全国地区总表：先把地点放对

下面按便于记忆的地理分区排列，分区不是考纲另设的考试范围。行政中心列按省会、自治区首府、直辖市及特别行政区实际情况填写；直辖市与特别行政区不另设“省会”。简称列保留教材常用的多简称。

2. 世界遗产：所在地、类型分开记

世界文化遗产、世界自然遗产、文化与自然双重遗产要区分；文化景观属于文化遗产范畴。世界遗产、国家5A级景区、世界地质公园是不同体系，获得一个称号不自动取得另外两个。

要对照的项目 所在地 遗产类别／易混点
泰山、黄山 山东、安徽 均为文化与自然双重遗产
峨眉山—乐山大佛 四川 文化与自然双重遗产；包含文化价值和自然价值
武夷山 福建、江西 文化与自然双重遗产
九寨沟、黄龙 四川 均为世界自然遗产
武陵源、神农架 湖南、湖北 均为世界自然遗产；省份不能换
苏州古典园林、杭州西湖文化景观 江苏、浙江 均为世界文化遗产
福建土楼、开平碉楼与村落 福建、广东 均为世界文化遗产
澳门历史城区 澳门特别行政区 世界文化遗产；不在香港

名录题的记忆单位是“准确项目名—所在地—类别”。 不用“看上去自然／古老”代替分类；中国南方喀斯特等系列遗产跨多个地区，遇到“只位于某省”要核实组成地。

3. 云南12景点：先背地点，再背类别

这12处来自云南中文面试范围，放在这里用于笔试地理关联；不能据此删去全国其他地区，也不能认为12处全是世界遗产。下表中的“非独立列名”仅表示不应把该景区名称直接当作一个独立世界遗产项目，不否认其其他保护或景区称号。

景点 具体所在地 遗产／知识对应
昆明石林 昆明市石林彝族自治县 中国南方喀斯特的组成地之一，世界自然遗产；彝族阿诗玛文化
玉龙雪山 丽江市玉龙纳西族自治县 高山冰川、垂直自然带；不把“玉龙雪山”写成独立世界遗产项目
丽江古城 丽江市 世界文化遗产；纳西文化、水系、城镇生活
崇圣寺三塔文化旅游区 大理州大理市 白族文化、大理历史；三塔不等同丽江古城
中国科学院西双版纳热带植物园 西双版纳州勐腊县勐仑镇 热带植物、傣族文化关联；不在景洪市城区
普达措 迪庆州香格里拉市 高原湖泊湿地；属都湖、碧塔海；不另立为同名独立世界遗产项目
火山热海 保山市腾冲市 火山、地热；大滚锅；热泉不等于都能直接接触或沐浴
和顺古镇 保山市腾冲市 侨乡文化、和顺图书馆、艾思奇故居；与火山热海同属腾冲
普者黑 文山州丘北县 喀斯特湖泊湿地、村落景观；不在红河州
红河哈尼梯田 红河州，核心区在元阳县 “红河哈尼梯田文化景观”，世界文化遗产；森林—村寨—梯田—水系
澄江化石地博物馆 玉溪市澄江市 关联“澄江化石地”世界自然遗产；博物馆名称与遗产项目名称分清
景迈山古茶林 普洱市澜沧拉祜族自治县 “普洱景迈山古茶林文化景观”，世界文化遗产；不是单纯自然遗产

另记：云南三江并流保护区是世界自然遗产，三江为金沙江、澜沧江、怒江。不要把“并流”说成三江汇合，也不要把某景区在区域内直接等同于其全部范围均纳入遗产边界。

**云南文化与自然对照：**文化遗产记“丽江古城—哈尼梯田—景迈茶林”；自然遗产记“三江并流—澄江化石地—中国南方喀斯特中的石林”。本组用于分类对照，完整及新增名录查官方。

4. 民族文化：按关联记，不记成排他标签

民族／文化区域 代表性文化关联 容易混淆的点
傣族 泼水节、孔雀舞；云南西双版纳等地 泼水节也见于其他相关族群与地区，不能写成傣族独有
彝族 火把节、阿诗玛；云南石林等地 火把节不只一个民族过
白族 大理三月街、扎染、三坊一照壁 大理白族文化与丽江纳西文化要区分
纳西族 东巴文化、东巴文字；丽江 不能把东巴文化配给白族
哈尼族 梯田生产文化；云南红河 梯田价值包含长期生产生活，不仅是地貌外观
布朗族、傣族等 景迈山茶文化与林下茶种植 茶林文化由社区共同维系，不把遗产归为单一树种
蒙古族 那达慕、长调、马头琴 与藏族雪顿节、藏戏区分
藏族 雪顿节、藏戏、唐卡等 雪顿节的典型地点在拉萨，不因云南有藏族就移植地点
壮族 “三月三”、壮锦；广西 壮锦与蜀绣、湘绣不是同一工艺门类
黎族 传统纺染织绣技艺；海南 与广西壮族文化分开记

5. 复习时怎样用这张表

  1. **第一轮只记地点：**遮住“省会／首府”和“所在地”列，每次记6—8行；说不出就标“未记住”，不凭熟悉感打勾。
  2. **第二轮再配类别：**把世界遗产项目分成文化、自然、双重三组，先写分类，再核对具体项目名。
  3. **第三轮交叉：**用“景点→地区”“地区→代表文化”双向回忆。能排除一个错误选项，不等于已能主动说出正确地点。
  4. **交给其他 agent：**先读学习记录，已答对的具体点跳过；本表尚未提问的地区知识标“未验证”，少量诊断后再决定补哪组。
