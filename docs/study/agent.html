必须纠正的历史讲解与出题问题

  1. 执业不是“挂靠平台”就行。《旅游法》第37条：取得资格后，与旅行社订立劳动合同或者在相关旅游行业组织注册，申请取得导游证；第40条要求提供导游服务接受旅行社委派。“注册”不是导游证本身。
  2. **口头变更不是一律无效。**不得擅自变更，应依法协商确认内容、权限、费用与责任并留证；具体形式依适用法律、合同及事项判断。不能把原题的简化处理背成绝对法律规则。
  3. 世界遗产原题 A 有歧义。“有文化和自然两类”没明确说“只有两类”，不能据此算用户多选错。常用类别为文化、自然、文化与自然双重；文化景观归文化遗产。本题不用于统计整题正确率。
  4. **“三甲”不能与“前三名”混写。**第一甲三人为状元、榜眼、探花，赐进士及第；第二甲赐进士出身；第三甲赐同进士出身。原选项“殿试三甲赐进士及第”表述应澄清，不根据用户排除 D 推定已经会完整对应。
  5. 面试练习中“第一句不超过十个字”“一定说三句话”只是当时训练限制，不是官方评分标准。语音转写的“呃”、断句也不能直接等同知识错误。
