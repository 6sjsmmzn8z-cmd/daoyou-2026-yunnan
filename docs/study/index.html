如何记而不只是再看一遍

  1. 一次选一张小表，先理解分类依据，再遮住答案列说出对应关系。
  2. 对认错的成对辨析：例如“君山银针—黄茶”与“白毫银针—白茶”；“宋应星—天工”与“徐光启—农政”。新补充的白毫银针归类仍属未测，不自动记为已会。
  3. 不只背选择题字母。换成“书名问作者”“作者问作品”，才知道是否真正记住。
  4. 新一轮交给 Agent 时，它先读取当天记录与进度文件，按漏点续练，别再刷已通过的常识题。
