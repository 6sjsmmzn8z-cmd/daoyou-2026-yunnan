# 2026全国导游资格考试资料包

为云南省昆明市中文类整理，检索与保存日期为2026年11月14日。

## 从这里开始

1. 阅读配套《研究与预测复习册.pdf》，含研究结论、2026重点、最后一周计划、云南12景点提纲、24道面试预测问答、100道原创专项训练及解析。
2. 用浏览器打开“资料索引.html”，可按标题搜索本地文件与原始来源；“资源总表.csv”可用Excel打开。
3. 先读2026官方笔试大纲与云南面试大纲，再用历年回忆题、课件和笔记查缺补漏。

本包检索251个不同来源URL，233个来源成功保存；按内容去重后229份原始资料文件，包括104份PDF、113份网页存档、6份DOC合同、1份DOCX附件、2份ZIP和3份RAR。18个最终未下载成功的来源保留URL与失败原因。PDF已作解析完整性检查，ZIP已作CRC检查；未逐页审校所有第三方题目，RAR内部内容未在本环境展开核验。

## 内容与范围

- 官方文件：2026笔试大纲和考务通知、云南2026面试大纲政府转载原件、2026团队旅游合同六份示范文本、“十五五”旅游强国规划、导游管理制度、GB/T15971—2023公开附件等。
- 历年题：已收集2019、2020以及2022—2025等年份的回忆题/参考题；科目和完整程度不同，不是每一年每科都有经认证的完整真题。
- 复习材料：模拟试题、思维导图、知识点、考前摘要、时政与面试问答。旧版本保留原年份，不代表2026全部适用。
- 教学资料：出版社公开课件RAR和样章；高校MOOC、培训及视频课程入口，另有商业题库与教材信息。
- 原创整理：reports目录内5份文稿及HTML版本、100题CSV/JSON。可编辑DOCX和打印PDF附于包内。

“原始资料229份”和“233个保存成功来源”口径不同：多个URL可能返回相同文件。manifest.json记录当前路径、来源、哈希与分类；download_attempts.json保留整理前的抓取尝试历史，其中旧文件名不作为最终路径。stats.json是原始资料统计，不包含新编复习册与索引等文件。

## 必须区分的状态

保存了课程介绍页不等于下载了课程视频；保存了出版社样章不等于取得整本书。没有取得公开授权的2026四本完整商业教材PDF或付费课程视频。公开题库网站自述的题量和免费范围不代表已经逐题保存或验证。

扫描原件保留PDF；text目录含提取文字与OCR，OCR有错字，仅辅助检索，背诵时对照原件。部分网页存档含原站链接和脚本，不能保证脱机完整使用。

“预测”是依据大纲和有限历年样本制定的复习优先级，没有泄题资料，没有经过验证的命中概率。完整资料包也不表示穷尽全网。特别关注科三科四各占合卷50%，以及2026新增政策、安全内容。云南中文面试需按12景点各自团型与规定顺序准备。

## 目录

- official：政府原文件、政策和标准等。
- papers：第三方回忆题、复习PDF、压缩包与出版社教学资料等。
- pages：页面存档，含课程和题库入口。
- text：可检索文本和扫描大纲OCR。
- reports：原创研究、预测、面试准备、试题和答案。
