# 导游业务：按“谁负责—何时做—先后顺序”记忆

这份提纲依据2026年大纲组织复习，不代表官方命题频率，也不是完整教材。你已经答对几道基础安全、沟通题；这只能证明那些具体判断通过，不能据此把服务流程、职责分工或整个安全专题标为掌握。下列未练内容均为**尚未验证**。

## 1. 先建一条服务时间线

**准备 → 迎接 → 入住 → 商定并落实日程 → 游览与生活服务 → 送行 → 后续总结。**

| 环节 | 要主动回忆的动作 | 容易漏掉的边界 |
|---|---|---|
| 接团前 | 核对接待计划、人数、交通班次、抵离时间、服务标准；联系司机和接待单位；准备资料和应急信息 | 计划中的时间与交通工具实际动态都要核实 |
| 迎接 | 确认团号、客源、人数和接待对象，清点人及行李，介绍自己、司机和必要事项 | “看见像自己的团”不等于身份核实 |
| 入住 | 协助办理入住、说明设施与安全事项、确认集合及后续安排，处理客房问题 | 尊重隐私；重要信息要让游客听清、理解 |
| 日程与游览 | 按约定落实安排，说明路线、集合、安全和文明要求；与相关人员协调 | 满意度不能作为擅改合同的理由 |
| 送行 | 核实交通信息、出发安排、人数、证件、行李和结算交接 | 不凭旧消息估计班次；不套用未经核实的提前到达分钟数 |
| 后续 | 处理遗留问题、完成记录与反馈、总结服务 | 送走团队不等于遗留事项自动结束 |

记法：每个环节都问自己“**人、物、时、地、标准、风险**核对了没有”。这是一种复习检查法，不替代标准原文。

## 2. 分清角色，再判断责任

- **地陪**：重点是团队在当地的接待安排、讲解、生活服务、协调与问题处理。
- **全陪**：重点是旅游全程的衔接协调、与各站地陪合作，维护并落实全程接待计划。
- **领队**：重点是出境团队的组织协调、出入境协助、境外衔接及与境外接待人员配合。

三者会协作，不能机械理解为“有全陪，地陪就不管安全”或“有地陪，全陪就不管行程”。做题先圈**所在阶段、地点、角色、权限**，再选动作。

## 3. 接送事故：先辨概念，再找原因

| 名称 | 抓住的区别 | 处理思路 |
|---|---|---|
| 漏接 | 团队已抵达，未按要求接到 | 尽快取得联系、落实接待、解释安抚，查明原因并报告协调 |
| 空接 | 按原计划前往迎接，却未接到应接团队 | 核实班次、抵达地点和计划变化，与旅行社联系后调整；不要凭猜测离开 |
| 错接 | 接走了其他团队 | 核实身份，联系有关接待方，安全交接、纠正错误 |
| 误机（车、船） | 未搭上原定交通工具 | 核实原因和后续交通，联系旅行社及承运方，安排等待期间服务并记录 |

“谁的责任”影响后续承担，但不能成为先把游客晾在一旁的理由。题目问**首要措施**时，先看当前是否有急迫危险，再看如何恢复接待和交通衔接；不要把“立即道歉”套成所有事故的第一步。

## 4. 应急处置：按场景排序

- **人员走失**：核实身份、最后出现时间地点和联系方式；保护其余团队安全，联系景区安保等组织搜寻；按紧急程度及时报警，保持家属和旅行社联络。儿童或其他高风险情况不能机械等待固定时长。
- **突发疾病或伤害**：优先排除现场危险、联系医疗急救并协助救助；安排团队照顾与联络，报告并保留必要记录。不得凭经验强行用药，也不要随意搬动疑似严重受伤者。
- **疑似食物中毒**：及时就医、报告并配合处理，协助保留食物、就餐和人员症状等线索；不要为赶行程隐瞒。
- **火灾、洪水、泥石流等**：按现场预警及专业人员指引组织避险、清点人员、联络救援。不同灾害的逃生方式不同，不能只背一句通用口号。

2026大纲明确涉及：导游专座、客运安全带、船用救生衣、行前安全告知，以及高原、温泉、冰雪、沙漠、研学等活动风险。要记到**具体场景和动作**，不是只记“注意安全”。

## 5. 个别要求、纠纷与特殊团型

自由活动、中途退团、亲友随团及服务变更，先核实要求和合同条件，再说明风险、协调权限与费用，按程序确认并留痕。**口头协商不当然一概无效，签字或风险告知也不能当然免除全部法定义务。**

投诉处理可按“倾听—核实—记录—协调—反馈”回忆；避免未经核实就推责、争辩，或承诺超出权限的赔偿。

| 团型 | 内容与组织上的调整 |
|---|---|
| 老年团 | 关注行动与健康差异，节奏适宜，休息合理，信息表达清楚 |
| 亲子团 | 同时兼顾儿童与家长，明确照护和集合安排，设置适龄互动 |
| 研学团 | 围绕学习目标组织观察和活动，兼顾未成年人保护与安全 |
| 商务团 | 注意时间效率、内容相关性与隐私，避免未经核实的商业承诺 |

记法：**对象不同，需求、节奏、讲解和风险都要相应调整**；不能只换称呼。

## 6. 讲解方法：用“动作”区分名称

- **分段讲解**：依参观线路或内容层次分段组织。
- **突出重点**：围绕最有代表性的内容展开，避免平均用力。
- **虚实结合**：实景、史实与传说相结合；必须说明传说性质，不能当作科学成因。
- **触景生情**：由眼前景物引发感受和联想。
- **制造悬念**：先设疑问，吸引注意，再逐步揭示。
- **问答法、类比法**：前者通过提问互动，后者用熟悉事物帮助理解陌生事物。

判断题干中**实际用了什么手段**，不要仅凭“有故事”“有感情”判断。语言力求准确、清楚、贴合对象；没有必要把人为限定的句数、字数当作考试合格标准。

## 7. 计算、证件和行李：单独做小卡

时差统一写成：**目的地时间＝已知地时间＋目的地UTC偏移－已知地UTC偏移**，算完检查是否跨日。例：北京UTC+8的11月20日02:00，UTC+3地区是11月19日21:00；题目如涉及夏令时须另按条件处理。

温度换算：华氏温度＝摄氏温度×9/5＋32。证件、海关、托运行李和离境退税要分清**适用对象、条件、办理主体、限额或期限**；政策会变，数字按现行正式规则核对，不能直接背旧回忆题。

行李问题先辨明发生在**运输、接收交接、运送途中还是饭店**，核对行李凭证和交接记录，再联系相应单位协助处理；不要未经核实直接认定某一方赔偿。

## 8. 闭卷自检与下一步

合上材料，分别写出：一次接团的核对清单；漏接、空接、错接各一句区别；全陪与地陪各两项职责；游客走失时需先核实的信息；一道跨日时差的算式。写不出的部分回到对应段落，转成“条件—动作—理由”的记忆卡。
