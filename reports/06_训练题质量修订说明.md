# 训练题质量修订：清理低区分度题，保留个人学习证据

修订日期：2026-11-16。

## 第一版的问题

用户反馈原题干扰项过于明显，靠常识或排除荒唐选项就能答对，无法发现知识缺口。逐题检查发现：

- 20道多选全部只有一个错误项，形成“全选减一”的固定套路。
- 40道单选解析套用“注意法律条件、分类或时点”，20道多选解析套用“其余选项不符合”，没有解释关键差别。
- 导游业务10道单选中，9道的正确项严格最长，容易暴露答案。
- 《茶经》作者、石林地貌、《营造法式》年代、三峡名称等有换题型重复。
- 原题将私人病历、家庭住址混入维权证据，将“强迫交易”混入园林手法，将跨领域选项混入化石价值，未有效考查专业辨析。

这些是内容与结构问题的检查结果，不是基于真实考生样本计算的区分度系数。

## 本版处理

1. 主训练库替换为100道原创进阶练习，四科各25题，每科15单选、10多选。题号101—200，与历史题分开。
2. 干扰项使用同层级的相近概念、地点、程序与条件；避免明显荒唐、跨领域、失德选项。不能只把句子写长就称为提难。
3. 多选正确数量变化，检查单选正确位置与选项长度，不提供机械猜题套路。
4. 解析说明正确依据及关键错误项为什么不成立；大纲用来确定范围，不单独证明事实细节。
5. JSON是题库唯一数据源，脚本同步生成CSV、题目与解析Markdown/HTML、在线题库和下载复习册。
6. 知识点标签可能含答案，只在作答后的解析显示。
7. 网页新增四科分类表、学习记录入口，以及页尾“上一篇／下一篇”，支持连续阅读。

“进阶”是本资料的编排定位，未经过真实样本校准，不代表官方难度、真题或命中保证。题型比例不等同正式试卷，不据此推定正式考试多选漏选计分。

## 个人学习记录保持独立

先读[Agent必读](../AGENT必读_学习记忆与续练规则.md)与[进度JSON](../study/progress.json)。旧题下线不清空作答证据，不把已经答对的具体点重新问一遍。仅看过新表或解析不能标为复测通过；未练的新点仍是“未验证”。网站隐藏已答对题是当前页面会话功能，不伪称已经自动验证长期掌握。

第三方回忆题与原始资料仍作为标明来源的档案保留，不把它们冒称本套题的官方背书。

## 维护命令

```bash
python3 scripts/build_practice.py --book
python3 scripts/build_site.py
python3 scripts/check.py
```

`--book` 使用Pandoc与PyMuPDF同步重建 `study.docx`、`study.pdf`。不带参数只更新题目导出。不要手改导出的HTML或网页内嵌题库，以免下次生成覆盖或出现版本不一致。
