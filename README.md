## iPhone / iPad 怎么看、怎么下载

- **先看复习册：[study.pdf](study.pdf)**，共32页。文件页面选择下载按钮；在 Safari 中可通过“分享 → 存储到文件”保存至“我的 iPhone”或 iCloud 云盘。
- **一次下载全部资料**：仓库首页选择绿色 **Code → Download ZIP**。解压后打开 `README_先读我.md` 或 `资料索引.html`。
- **更方便的完整包与核心包**：发布者运行发布脚本后，可在仓库的 **Releases** 中找到 `guide-all.zip`、`guide-core.zip`、`study.pdf` 和来源表。未发布 Release 时，仍可使用 Code → Download ZIP。
- 如果仓库为私有，请先在 Safari 登录获得访问权限的 GitHub 账号；只有获得权限的设备/账号才能下载。

本库默认按**私有仓库**准备发布；这里的说明不表示远程仓库或 Release 已经发布。

## 复习提醒

2026大纲明确科三、科四在合卷中各占50%；科目四覆盖全国各地区，不能只学云南。云南中文面试按指定12景点、各自团型与规定顺序准备。请以官方通知和准考证确认考试时间、地点及本年操作要求。

“预测”是依据大纲与有限样本制定的复习优先级及原创练习，不是泄题资料，没有经过验证的命中概率。第三方回忆题含错录、缺项及可能过时答案，不能当作官方答案。

## 本地校验和发布

需要 Python 3.10+；发布另需 Git 和已登录的 GitHub CLI。

```bash
python3 scripts/check.py
python3 scripts/build_downloads.py
bash scripts/publish.sh
```

发布脚本默认创建私有仓库 `daoyou-2026-yunnan`，推送当前分支，并上传完整资料包、核心包、复习册和来源表到 Release。脚本不会覆盖已有同名远程仓库，也不会强制推送。可通过第一个参数指定其他仓库名称。

另一种方式是在GitHub手动触发 `Package study materials` 工作流，下载其产物；选择发布选项可创建或更新一个独立的资料下载Release。仓库是否公开由拥有者另行决定。
